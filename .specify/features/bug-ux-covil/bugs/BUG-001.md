## Description
O selo/flag de "Covil do Lich" e "DDAL" para as mesas correspondentes não é exibido nos ambientes de produção nem no de dev, mesmo após o fix ter sido supostamente implementado na base de código (Erro catalogado anteriormente como E157). O sintoma aponta para uma falha no pipeline de renderização, no build ou em cache, onde o código em runtime não reflete a correção da lógica de flags no frontend.

## Root Cause Analysis
A investigar. As hipóteses principais são: (a) o commit com a correção de `TableCard` ou do backend `gmPanel.ts` nunca chegou de fato à branch `main`/`dev`; (b) o build do Vite falhou silenciosamente; ou (c) os dados do banco real em produção/dev não possuem a flag `is_covil` populada para as mesas testadas, mascarando o fix. A verificação do código atual em `dev` comparado ao que roda no servidor é necessária.

2. Validar payload do backend (`/gm/tables`) nos ambientes `dev`/`prod` para confirmar a presença de `is_covil`.
3. Executar o fluxo `/speckit.bugfix.patch` quando a causa exata for localizada.
