# Bug Report: BUG-002

**Type**: Implementation drift
**Severity**: Medium
**Status**: Patched
**Patched**: 2026-04-24
**Feature**: bug-ux-covil
**Reported**: 23/04/2026

## Description
Mesas com imagens (banner/avatar) válidas aparecem com a imagem de placeholder padrão no painel do mestre, embora a imagem apareça corretamente em outros contextos como o catálogo público e na página de detalhe. (Verificado nas mesas do usuário 'albuquerque' e em 'Forgotten Realms').

## Catalog Lookup
- **Lookup status**: Known error match
- **Catalog ID**: E157
- **Catalog source**: `.specify/memory/errors.md`
- **Matched symptom**: Este erro aparenta ser um desdobramento das inconsistências de payload/componentização reportadas no E157, especificamente na rota de painel (`gmPanel.ts`) e seu componente (`TableCardDashboard.tsx`).

## Artifact Traceability

### spec.md
- **Affected user story**: Caso Placeholder (Mestre vê placeholder indevido no seu painel).
- **Affected requirements**: REQ-02 (Imagens no Painel do Mestre).
- **Gap identified**: O payload da rota autenticada `/gm/tables` ou a injeção de props no componente `TableCardDashboard` diverge da lógica usada na rota pública, caracterizando implementation drift (o código real não mapeia a URL da imagem de maneira idêntica à lista pública).

## Root Cause Analysis
A investigar. O componente `TableCardDashboard` (ou a query associada) pode estar esperando `cover_url` em vez de `banner_url`, ou a rota de back-office do mestre (em `gmPanel.ts`) pode estar abstraindo ou omitindo os campos de imagem presentes na query pública. Outra possibilidade é o mapeamento de null/undefined do banco falhar em fornecer fallback apenas num componente, aplicando um placeholder fixo desnecessariamente.

## Recommended Fix
1. Auditar o retorno de `/gm/tables` na aba de network comparando com o retorno de `/tables` (pública).
2. Revisar o mapeamento de props dentro de `TableCardDashboard.tsx` no frontend para imagens.
3. Executar o fluxo `/speckit.bugfix.patch` com a solução mapeada.
4. Run `/speckit.bugfix.verify` to confirm consistency.
