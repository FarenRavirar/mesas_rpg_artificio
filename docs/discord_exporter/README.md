# Documentação DiscordChatExporter (organizada)

Este índice organiza a documentação operacional do exportador de mensagens do Discord para uso no projeto.

> [!WARNING]
> **Nunca compartilhe token** (de usuário ou bot). Token é equivalente à senha.

> [!IMPORTANT]
> Automação com conta de usuário (self-bot) pode violar os Termos do Discord e levar a bloqueio de conta.
> Sempre prefira **conta bot oficial** quando possível.
