# Bug Report: Mensagens importadas sem fluxo de triagem

**Type**: Spec gap
**Severity**: High
**Feature**: `specs/015-discord-forum-threads/`
**Reported**: 2026-05-04
**Status**: Patched
**Patched**: 2026-05-04

## Description

O backend importou mensagens do Discord e a aba Mensagens listou os itens, mas o frontend não ofereceu ações suficientes para o administrador trabalhar a fila: não havia abertura de detalhe, conferência do conteúdo completo, atualização de status de triagem ou janela de tempo antes de carregar mensagens/posts.

## Artifact Traceability

### spec.md
- **Affected user story**: User Story 1 — Importar anúncios de um fórum Discord; também afeta o fluxo preservado de canais textuais/anúncio.
- **Affected requirements**: FR-006, FR-007, FR-013.
- **Gap identified**: A spec exigia origem consultável e referências corretas, mas não explicitava que a mensagem importada precisava ser acionável na interface para apuração humana nem que toda busca Discord deveria aceitar janela de tempo.

### plan.md
- **Affected sections**: File scope for `backend/src/routes/adminDiscordSync.ts`, `backend/src/discord/ingestMessages.ts`, `frontend/src/features/discord-sync/api/discordSyncApi.ts`, `frontend/src/features/discord-sync/components/DiscordSourceList.tsx`, `frontend/src/features/discord-sync/components/DiscordSyncPanel.tsx`, `frontend/src/features/discord-sync/types.ts`, `MAPA_DE_API.md`.
- **Impact**: O plano precisa cobrir PATCH de status da mensagem, detalhe acionável no frontend e parâmetro temporal seguro para `POST /fetch` em qualquer tipo de fonte.

### tasks.md
- **Affected tasks**: T015 e T021 foram marcadas como completas, mas não cobriram a triagem funcional pós-importação.
- **False completions**: Nenhuma task precisa ser reaberta; a captura e exibição básica foram entregues, mas o fluxo de triagem é uma tarefa complementar.
- **Missing tasks**: Adicionar tasks para filtro temporal de busca, atualização de status de mensagem, painel de detalhe/triagem e validações.

## Root Cause Analysis

A entrega validou captura, origem e listagem, mas a experiência de operação real do administrador exigia um passo além: abrir cada mensagem, apurar o conteúdo completo, decidir próximo status e limitar a busca por período. Esse comportamento não estava escrito como requisito explícito.
