# Bug Report: Apuração não funciona como ferramenta de gestão

**Type**: Implementation drift
**Severity**: High
**Feature**: `specs/015-discord-forum-threads/`
**Reported**: 2026-05-04
**Status**: Patched
**Patched**: 2026-05-04

## Description

O botão "Apurar" na aba Mensagens apenas selecionava a linha. Em viewport desktop comum, o painel de detalhe ficava abaixo da lista por causa do breakpoint usado, então a ação parecia não fazer nada. A lista também não oferecia organização operacional suficiente para servir como ferramenta de gestão de mesas importadas.

## Artifact Traceability

### spec.md
- **Affected user story**: User Story 1 — Importar anúncios de um fórum Discord.
- **Affected requirements**: FR-014.
- **Gap identified**: A implementação entregou detalhe de mensagem, mas não garantiu visibilidade e fluxo de gestão na viewport real usada pelo mantenedor.

### plan.md
- **Affected sections**: `frontend/src/features/discord-sync/components/DiscordSyncPanel.tsx`.
- **Impact**: A UI precisa funcionar como painel mestre/detalhe persistente, com resumo de fila e ações rápidas de status.

### tasks.md
- **Affected tasks**: T032.
- **False completions**: T032 precisa de complemento funcional, mas não de reabertura do BUG-001.
- **Missing tasks**: Adicionar tarefa de UX funcional para painel de gestão.

## Root Cause Analysis

O layout usava `xl:grid-cols`, exigindo largura maior do que a tela comum do mantenedor. O clique estava conectado ao estado, mas o resultado visual ficava fora da primeira dobra. Além disso, mensagens sem `content_raw` ficavam com prévia vazia, reduzindo a utilidade operacional da lista.

## Recommended Fix

1. Ajustar o layout para duas colunas em `lg`.
2. Manter item selecionado automaticamente.
3. Adicionar resumo de fila e ações rápidas de triagem.
4. Usar fallback de título/origem quando a mensagem não tiver texto bruto.
